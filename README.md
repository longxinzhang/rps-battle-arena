# World of RPS

当前开发版本：`0.2.6`。

从原始 `rps_battle.html` 扩展出来的可继续做大的版本。原版保存在 `legacy/rps_battle_original.html`。

开发规范和模块化路线见 `DEVELOPMENT.md`。

## 运行

单机玩法直接打开 `index.html` 可以运行。要使用多人同步竞猜房间，需要在本目录启动内置房间服务：

```bash
node server.mjs
```

然后访问 `http://localhost:5173`。

如果只想运行静态单机版本，也可以使用：

```bash
python3 -m http.server 5173
```

静态服务下竞猜房间会自动退回本机模式，不能多人同步。

## HarmonyOS NEXT

鸿蒙 NEXT 工程位于 `harmony-next/`，可用 DevEco Studio 打开并运行到手机、平板或模拟器。当前版本使用 ArkTS + ArkUI 创建应用壳，通过 ArkWeb 加载内置在 rawfile 中的本地游戏资源。

Web 版改动后，同步到鸿蒙工程：

```bash
node harmony-next/scripts/sync-web-assets.mjs
```

## 玩法开关

- 默认只开启基础观战：三方自动追捕、躲避、碰撞转化。
- 阵营主题可切换：保留原始 RPS，也可换成颜色球、国家队或虚构品牌战；非 RPS 主题可自定义三方名称。
- 初始人数默认每方 10 个，最少 3 个；人数同步开启时改任意一方会同步三方，关闭后可分别设置。
- 游戏设置：可在开场页或游戏中调整 BGM、音效音量，以及是否显示游戏通知。
- 游戏预设：开场可一键套用“经典大乱斗”“团队占点”“小心叛徒”“众生平等”；预设人数会按设备宽度设为桌面 30、手机 7。
- 开场可设置单局秒数，默认 60 秒。
- 上帝之手默认关闭：可在开场或底部按钮开启，用鼠标或手指推开/吸引附近单位。
- 下注模式默认关闭：开启后先选择支持选手，再 3·2·1 倒计时开战，猜中按赔率加积分。
- 竞猜房间：当前入口暂时隐藏，代码保留。通过 `node server.mjs` 启动后仍保留房间号同步竞猜能力，后续可恢复入口继续迭代。
- 多局赛制默认关闭：开启后可选三局两胜或五局三胜，胜方下局削弱。
- 死斗模式默认关闭：开启后无视时间，直到一方完全霸屏。
- 据点争夺默认关闭：场上生成 3 个占领区，占点得分先到目标分也能获胜。
- 机制默认关闭：可选地形障碍、缩圈、悬赏头名。缩圈会进入终局压缩并自动裁定，避免死局。
- 悬赏头名：一家明显领先时，另外两家会追猎头名；转化头名单位会获得短暂反打奖励。
- 精彩事件默认关闭：可选“我们中出了个叛徒”、黑洞、加速/护盾/分裂道具、“我要打十个”、绝地求生救场。
- 能量道具：除单体加速、护盾、分裂外，会随机刷新团队版道具，让碰到者同派全员获得效果。
- 我们中出了个叛徒：游戏开始 10-15 秒如果只剩两方，会提前出现 1 个叛徒救场；常规逻辑是 20 秒后每 10 秒随机抽 1-2 个阵营，各出现 1 位顶着紫色倒计时圈的叛徒，2 秒后叛变到另外两派之一。
- 黑洞：随机刷新并吸引附近单位，碰到会被吞掉；每吞掉 1 个单位，体积和吸附范围增加 30%。
- 我要打十个：场上只剩两方且少数方被十倍以上优势方克制时，有概率触发 10 秒反杀；少数方速度提升、体型放大、只杀不转化，成功清场会以弱胜强。
- 绝地求生：某一派只剩 1 个时大概率分裂；如果最后一个被消灭或转化，小概率 5 秒后原地复活。
- 灭霸响指：随机华丽登场，播放 `assets/y2155.mp3`，响指后每个派系消失一半。
